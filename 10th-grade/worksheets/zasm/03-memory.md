# Работа с памятью

## A4. Элемент массива

К нам на склад завозят N коробок с малиной.
Для каждой коробки нам сообщают сколько там килограммов малины.

А затем приходит покупатель и спрашивает – сколько килограммов малины в коробке под номером i?

## B4. Обмены

В ряд лежит N коробок с апельсинами.

Мы знаем сколько апельсинов в каждой коробке.

Но пришли шалуны Петя и Вася и Q раз поменяли некоторые коробки местами.

Сколько апельсинов в каждой коробке после всех обменов?

## C4. Разворот

Вам дано N чисел.

Выведите их в обратном порядке!
