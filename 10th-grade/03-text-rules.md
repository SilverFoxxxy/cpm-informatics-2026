# Правила оформления и символы

## Правила

Некоторые простые правила оформления текста:

- Разбиение на предложения.
- Начало предложения с заглавной буквы.
- Пробелы:
    - Ставим по одному пробелу (а не по два): `слово слово`
    - Пробел только **после** точки (или запятой, двоеточия и т.д.): `слово. Слово` и `слово, слово`

- Разбение на абзацы.

## Символы

Есть три символа, которые легко перепутать в использовании.

1. **Дефис (-)** — часть слова, без пробелов.

    Пример: *ярко‑красный, по‑русски*.

2. **Среднее тире (–)** — для диапазонов (без пробелов) и как замена длинного тире (с пробелами).  

    Примеры: *10–20 минут*; *Москва – столица России*.

3. **Длинное тире (—)** — по строгим правилам для пауз и противопоставлений.  
    
    Пример: *Он пришёл — и всё изменилось*.

**На практике** в цифровых текстах (чаты, конспекты, Markdown) спокойно используют:
- **Дефис** — в быстрых сообщениях;
- **Среднее тире** — как универсальный вариант вместо длинного тире.
