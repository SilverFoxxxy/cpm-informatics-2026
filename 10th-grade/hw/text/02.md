# Markdown

Это задание на использование `markdown`.

- Прочитайте что такое markdown и посмотрите примеры использования в файле [markdown.md](../../02-markdown.md)
- Структурируйте текст с использованием markdown

Возможные темы:
- Описание и правила какой-нибудь игры – для начинающего игрока
- Описание использования инструмента (н-р программы или сайта) – для начинающего пользователя
- Описание любой техники (ноутбук, планшет, телефон) - для покупателя
- Инструкция по эвакуации – для учителя и класса
	- Порядок действий
	- Отдельно – номера

Редакторы markdown:
- Obsidian
	- Приложение для заметок
	- На Windows, Linux, MacOS
	- На Android, iOS
- Visual Studio Code
	- Есть предпросмотр markdown
- Онлайн-редактор:
	- Любой результат поиска по фразе `online редактор markdown`
	- [coddy.tech](https://coddy.tech/tools/ru/markdown-editor)
