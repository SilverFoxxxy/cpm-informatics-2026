Markdown – упрощённый и человекочитаемый способ разметки текста. Так как он конвертируется в html – в нём можно использовать и html вставки.

[The Ultimate Guide to Markdown](https://gist.github.com/cuonggt/9b7d08a597b167299f0d)

Рассмотрим простейшее оформление на примере markdown:

## Заголовки

````
# Заголовок

## Подзаголовок

### Заголовок 3

#### Заголовок 4

##### Заголовок 5

###### Заголовок 6
````

# Заголовок

## Подзагаловок

### Заголовок 3

#### Заголовок 4

###### Заголовок 6

## Текст

````
Обычный текст

**Жирный текст**

*Курсив и **жирный курсив** и снова обычный курсив*

~~Зачёркнутый текст~~

<ins>Подчёркнутый текст<\ins>

> **Примечание:** примечение примечание
> продолжение примечания<br>следующая строчка

## Код

````
Встроенный в текст: `a[n] = {1, 2, 3, ..}`, `nano`

Отдельный
```
c = a + b
print(c)
```

Код с подсветкой
```c++
int main() {
	cout << "Hello, World!\n";
}
```
