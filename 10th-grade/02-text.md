# Текст

Рассматриваем текст как набор символов (без использования заголовков, жирного или курсивного текста и т.д.).

Такой текст уже можно:

- Разделять на абзацы
- Структурировать
- Редактировать и пересылать

Пример текста:

```
Джунгарский хомячок, джунгарик, ручной.
Мальчик, 28.09.2026г.р. по всем вопросам пишите здесь, только самовывоз. Наличие коробочки для переезда джунгарика уточняйте заранее
```

## Типы текста

Примеры типов текста:

- Сообщение
- Заметка
- Письмо
- Объявление о продаже
- Вакансия
- Описание видео
- Рецепт
- Инструкция
- $\cdots$

## Хороший текст

**Что такое хороший?**

- Как по тексту понять, что он хороший или плохой?
- Что такое плохой текст?

**Стоит учесть**

1. Кто адресат
2. Какая у текста цель
3. Контекст (это соц. сеть, официальное письмо или что-то другое)

## Ошибки

Возможные ошибки

- Грамматические
- Пунктуационные
- Логические
- Фактические
- Структурные
- Стилистические

> **Упражнение**<br>Предложите несколько критериев для оценки текста.
